FEATURES:
=========
✅ Landing Page with Clerk Secret Unlock
✅ Role Selection (Patient / Admin)
✅ Patient Portal:
   - Patient login (name + ID only)
   - Feedback submission with NLP sentiment analysis
   - Floating chatbot (FAQs: visiting hours, cafeteria, emergency)
   - Auto-saves feedback via chatbot
✅ Admin Dashboard:
   - Admin password authentication
   - Real-time statistics cards
   - Recharts Pie Chart (sentiment distribution)
   - Recharts Line Chart (7-day trends)
   - AI Analyst Chatbot (weekly insights, improvement suggestions)
✅ NLP Microservice:
   - TextBlob sentiment analysis
   - Keyword extraction from negative feedback
   - Actionable improvement suggestions

TECH STACK:
===========
Frontend: React 18 + Vite + Tailwind CSS + Axios + Recharts + Lucide Icons
Backend: Node.js + Express + Mongoose (MongoDB)
NLP: Python 3 + Flask + TextBlob + NLTK
